# E-Mail-Vorlagen für Südfrüchte Hohenlohe

## Enthaltene Vorlagen

1. **customer-reply-template.html** - Allgemeine Kundenantwort
2. **complaint-reply-template.html** - Reklamationsbearbeitung

## So verwenden Sie die Vorlagen

### In Outlook (Desktop)

1. Öffnen Sie die HTML-Datei in einem Browser
2. Markieren Sie den gesamten Inhalt (Strg+A)
3. Kopieren Sie ihn (Strg+C)
4. Öffnen Sie Outlook und erstellen Sie eine neue E-Mail
5. Fügen Sie den Inhalt ein (Strg+V)
6. Ersetzen Sie die Platzhalter:
   - `[KUNDENNAME]` - Name des Kunden
   - `[HIER IHREN TEXT EINFÜGEN]` - Ihr individueller Text
   - `[BESTELLNUMMER]` - Falls relevant
7. Speichern Sie als Vorlage: Datei → Speichern unter → Dateityp: "Outlook-Vorlage (*.oft)"

### In Gmail

1. Öffnen Sie die HTML-Datei in einem Browser
2. Markieren Sie den gesamten Inhalt (Strg+A)
3. Kopieren Sie ihn (Strg+C)
4. Öffnen Sie Gmail und klicken Sie auf "Verfassen"
5. Fügen Sie den Inhalt ein (Strg+V)
6. Ersetzen Sie die Platzhalter
7. Klicken Sie unten auf die drei Punkte → "Vorlage" → "Entwurf als Vorlage speichern" → "Als neue Vorlage speichern"

### In Apple Mail

1. Öffnen Sie die HTML-Datei in einem Browser
2. Markieren Sie den gesamten Inhalt (Cmd+A)
3. Kopieren Sie ihn (Cmd+C)
4. Öffnen Sie Mail und erstellen Sie eine neue E-Mail
5. Fügen Sie den Inhalt ein (Cmd+V)
6. Ersetzen Sie die Platzhalter
7. Speichern Sie als Entwurf im Ordner "Vorlagen"

## Platzhalter zum Ersetzen

- `[KUNDENNAME]` - Ersetzen durch den Namen des Kunden
- `[HIER IHREN TEXT EINFÜGEN]` - Ihr individueller Nachrichtentext
- `[BESTELLNUMMER]` - Bestellnummer (falls relevant)
- `[PRODUKT/LIEFERUNG]` - Spezifisches Produkt oder Lieferung

## Tipps

- Die Vorlagen verwenden Inline-Styles für maximale Kompatibilität
- Das Layout basiert auf HTML-Tabellen (funktioniert in allen E-Mail-Clients)
- Logo und Farben entsprechen Ihrem Branding
- Die Vorlagen sind responsive und funktionieren auch auf Mobilgeräten

## Anpassungen

Falls Sie Änderungen wünschen (z.B. andere Farben, zusätzliche Informationen), können Sie die HTML-Dateien mit einem Texteditor bearbeiten oder mich kontaktieren.
